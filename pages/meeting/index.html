Grabación 3 — 28/08/2026

Puntos relevantes

La reunión definió el alcance técnico y operativo inicial para digitalizar certificados de seguros colectivos.

  • Stack: Java 25, Spring Boot 4, React, Postgres y Linux.
  • Integración de usuarios y datos mediante el SFI.
  • Primera etapa: certificados digitales para desgravamen y garantías.
  • Cobranza bancaria y amortización contable quedan posteriores.
  • Se prioriza eliminar formularios manuales y automatizar asociaciones.
  • Migración de pólizas existentes sigue pendiente de validación.

Grabación 2 — 27/08/2026

Puntos relevantes

La reunión definió reglas operativas para digitalizar certificados y pólizas de seguros.

  • El módulo debe iniciar dentro de 30 días.
  • La póliza madre será el primer documento analizado.
  • Se parametrizarán plantillas por aseguradora y producto.
  • El alcance inicial llega hasta el plan de pago.
  • Se automatizarán primas, comisiones y conciliaciones.
  • Las cotizaciones usarán slips y comparaciones homogéneas.
