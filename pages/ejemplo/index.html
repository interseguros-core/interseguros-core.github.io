Abrir la hoja ↗
¿Cómo obtengo la URL?
  1. Abre la hoja → Extensiones → Apps Script.
  2. Borra el contenido de Code.gs y pega el archivo apps-script/Code.gs de este proyecto. Guarda.
  3. Selecciona la función setup y pulsa Ejecutar (acepta los permisos). Esto crea los encabezados.
  4. Implementar → Nueva implementación → tipo Aplicación web. Ejecutar como: Yo. Acceso: Cualquier usuario.
  5. Copia la URL que termina en /exec y pégala arriba.
